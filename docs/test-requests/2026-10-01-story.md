# The story drivers of every level, the shared story services (flags, skill points, nanotech, item stores) and the story map

## 1. Summary

Batch 6, lane `story`. The game has no script system: each level's story is class code calling engine helpers
(docs/plan/level_scripting.md). This job:

* **Shared services** (`rc_game::moby_update::story`): the global flags as one read / write view (G-SAV-010), the
  skill-point award (G-SAV-007: byte + jingle + banner) wired into every ported site, the direct item / max-health /
  health / bolt stores (G-SAV-005), the made-permanent and death-bit stores, the level exit (`0x2a29a0` → the travel
  lane's `cinematic::leave_level`). New `GameWrite` variants (`SkillPoint`, `Owned`, `Acquired`, `MaxHp`), new
  `HeroFields` stores (`head_request` 0x141410, `clank_hidden` 0x141628, `set_entry_pose` 0x141050 / 0x141060), new
  cinematic calls (`item_movie` = the level item-movie player `mpegs[64 + n]`, `save_as` = `memcard_Save(0, p)`,
  `camera_script_unless_script`), `start_scene` now sets game mode 2 at once (as `DialogStreamStart`).
* **35 story classes ported** on 17 levels (one instance each unless noted): Veldin 834; Aridia 786, 788, 1005; Kerwan
  890, 909; Eudora 1120, 1190; Rilgar 918, 919, 925; Blarg 1105, 1016 (= 1005's code); Umbris 436; Batalia 1130, 1144,
  1283; Gaspar 1290 (level01 code, placed on 09); Orxon 18, 1326; Pokitaru 23, 90, 298; Hoven 282, 328, 1404 (two);
  Gemlik 1353; Oltanis 851, 924, 1354; Quartu 1388, 1419, 1469; Kalebo 1377; the fleet 1428.
* **Shared NPC pieces**: `talking_npc::LookLayout` generalised (eye height, pitch / yaw factors, s16 timers, gate
  sequences, the "seen" rate) and split into `look_targets` / `look_springs`; `units::story_npc` (the idle fidgets, the
  talk radius rule, the grounded scene-end place, the child-on-joint helper `0x27b9c0`); `petal_door::{open, close}`
  (the calls `0x2f5360` / `0x2f53e8` other classes make).
* **The story map**: docs/plan/progression.md `## story` (every level's drivers, the planet chain, status).

Plug-and-play: a new story driver is a `classes/units/` module + one `UnitPort` row; NPCs = a `LookLayout` row +
`story_npc`; pickups = `gold_bolt::{glow_init, item_glow}`; stores = `moby_update::story`.

## 3. Behaviours to verify

Common setup: the level's data (extracted), a `World` with `Services` whose `interact.game` is synced from a fresh
`GameState` (`sync_game`), the class's moby placed from the level's instances (`RC_LEVEL`), talk tables loaded where the
class talks. "Talk node played" = talk block +0x04 (`talk::LAST`); "node" = +0x36 (`talk::NODE`). "Hidden" = mode bit 1
(and 0x40 where stated). Scene / movie / save requests are `svc.cinematic.requests` entries.
